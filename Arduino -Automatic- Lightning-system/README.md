
# Arduino Automatic Lighting System

## 1. Project Description
This project uses an Arduino microcontroller to control a light automatically using a sensor.

## 2. Objectives
- To automate lighting control.
- To reduce electricity wastage.
- To learn Arduino programming.
- To understand sensor applications.

## 3. Components Required
- Arduino Uno
- PIR Motion Sensor
- LED Bulb
- Relay Module
- Connecting Wires
- Breadboard
- Power Supply

## 4. Working Principle
The PIR sensor detects human movement and sends a signal to Arduino.

Arduino processes the signal and switches the light ON when movement is detected.

When no movement is detected, the light switches OFF after a programmed delay.

## 5. Programming Language
C++ (Arduino)

## 6. Applications
- Automatic home lighting
- Security lighting
- Energy saving systems
- Smart buildings
